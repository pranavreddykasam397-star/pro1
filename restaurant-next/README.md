# 🍽️ Heritage Restaurant — Next.js Application

This directory contains the main Next.js 16 (React 19, Turbopack, Tailwind CSS v4, tRPC v11, Drizzle ORM) web application.

For full architectural documentation, features list, and deployment guides, please see the [Root Project README](../README.md).

---

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Push database schema to Render PostgreSQL
npm run db:push

# 3. Seed menu data (124 authentic items)
npm run db:seed

# 4. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the Customer Storefront, or [http://localhost:3000/admin](http://localhost:3000/admin) for the Admin Dashboard.
